# Project Draugr — Overseer World Bible

This folder is a self-contained, static creator reference site. It is deliberately separate from the playable client and the backend simulation.

## What it documents

- Canonical world seed geography and ecology topology
- Biomes, resource sites, flora, wildlife, monsters, and native peoples
- Physical materials, harvest/recovery consequences, and industry chains
- Persistent-world rules and cross-sector consequences

Every catalogue card is labelled **Seed-supported**, **Topology required**, or **Blueprint**. A label is important: the Bible must never imply that a planned creature, material, or process is already active in the simulation.

The GitHub Pages workflow copies this folder to `/world-bible/` after the regular client build. No game source imports this site.
