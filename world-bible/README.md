# Project Draugr — Overseer World Bible

This folder is a self-contained, static creator reference site. It is deliberately separate from the playable client and backend simulation.

## What it documents

- Canonical world-seed geography and ecology topology
- Migration-backed flora, wildlife, monsters, native candidates, and mineral sources
- Physical objects, acquisition sources, harvesting, storage, and equipment compatibility
- Executable procedures with inputs, alternatives, tools, conditions, duration, and output
- Staged assemblies, construction kinds, infrastructure, industry, and fieldcraft
- Backdrop-registry coverage and persistent-world rules

## Catalogue snapshot

`catalogue-data.js` is generated by `generate-catalogue.mjs` from the repository's ordered PostgreSQL migrations and backdrop manifest. It contains no live GitHub API dependency. Cards link to local detail pages and expose the exact relationships present in the catalogue rather than extracting code words from issue descriptions.

The same generator reproduces the canonical `681013497` world-seed terrain and marker placement rules from `WorldGenesisService`. The Atlas therefore shows the current 28 × 20 chunk biome distribution and exact deterministic resource, wildlife, monster, and ruin sites rather than the earlier planning overlay.

Regenerate and verify after catalogue migrations change:

```powershell
node .\world-bible\generate-catalogue.mjs
node .\world-bible\catalogue-regression.mjs
```

The GitHub Pages workflow copies this folder to `/world-bible/` after the regular client build. No game source imports this site.
