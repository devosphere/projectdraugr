# 11.2 – Behavioral FSM

> **Project Draugr**
>
> *The world is intelligent because it is honest about cause and effect.*

---

# Purpose

This document defines the finite state machine (FSM) governing wildlife and monster behavior in Project Draugr.

The FSM produces emergent, lifelike behavior through deterministic rules evaluated on every ecology tick.

No language model is involved in behavioral decisions.

See DR-0018.

---

# Design Principle

The FSM must answer one question for every population on every tick:

**Given this species, this environment, this time of day, this season, and the current state of everything around it — what does this population do?**

The answer is always deterministic.

The behavior feels emergent because it responds to real context: a wolf pack does not hunt because the game tells it to hunt. It hunts because its hunger interval has elapsed, its activity cycle is active, and its population health is above the minimum threshold.

---

# Behavior States

Current states (V7, expanded V41):

| State | Description |
|-------|-------------|
| `RESTING` | Inactive; not feeding, not moving |
| `HUNTING` | Actively pursuing prey (carnivores/omnivores) |
| `FORAGING` | Searching for plant food or scavenging (herbivores/omnivores) |
| `SHELTERING` | Taking cover from weather or season (hibernation, storm) |
| `ALERT` | Threat detected; elevated response readiness |
| `FLEEING` | Actively retreating from threat |
| `STALKING` | Covert approach toward prey (ambush hunters) |
| `FEEDING` | Actively consuming food at a site |
| `DRINKING` | At water source |
| `MIGRATING` | Moving between chunks seasonally |
| `NESTING` | Defending breeding territory (spring) |
| `TERRITORIAL` | Expanded aggression zone during mating season |
| `PACK_HUNT` | Pack members coordinating active pursuit |

---

# Tick Evaluation Order

Each ecology tick evaluates states in this order:

1. **Season modifier** — hibernation, mating season, nesting check
2. **Weather modifier** — storm forces SHELTERING override
3. **Activity cycle check** — is this species active right now?
4. **Inter-species cascade** — does nearby predator state affect this population?
5. **Hunger interval** — has reproduction/feeding timer elapsed?
6. **State transition** — compute new behavior_state
7. **Flee window expiry** — FLEEING populations revert after 2h

---

# Core State Machine

## Activity Cycle Gate

Before any other evaluation, check whether the species is active at the current time of day:

| cycle | active period |
|-------|--------------|
| DIURNAL | 06:00–18:00 |
| NOCTURNAL | 20:00–04:00 |
| CREPUSCULAR | 05:00–08:00 and 17:00–20:00 |

If not in active period → `RESTING` (unless overridden by season or cascade).

---

## Weather Override

| weather_kind | effect |
|-------------|--------|
| STORM | All species → `SHELTERING` (overrides activity cycle) |
| HEAVY_RAIN | Aquatic species unaffected; others shift to `SHELTERING` or reduce activity |
| CLEAR | No override |

---

## Season Modifiers

Evaluated once per in-game day:

| Season | Species | State override |
|--------|---------|---------------|
| WINTER | Ursidae (bear family) | SHELTERING (full hibernation — no encounters) |
| WINTER | Migratory birds | population_count = 0 (departed) |
| AUTUMN | Cervidae (deer, elk, reindeer) | TERRITORIAL (rut — elevated aggression) |
| SPRING | All nesting birds | NESTING (defend nest site; aggression within 1 chunk) |
| SPRING | `maple_sap` flora | sap available |
| SUMMER_AUTUMN | Berry flora | yield available |

## Primary State Transitions

### Carnivore Logic

```
if SHELTERING_season or STORM → SHELTERING
else if NOT in activity_window → RESTING
else if hunger_interval_elapsed:
    if ambush_hunter → STALKING
    else → HUNTING
else if prey_chunk_has_carcass → FEEDING
else → RESTING
```

### Herbivore Logic

```
if SHELTERING_season or STORM → SHELTERING
else if NOT in activity_window → RESTING
else if food_available_at_chunk → FEEDING
else if water_needed → DRINKING (toward water chunk)
else if mating_season → TERRITORIAL
else → FORAGING
```

### Omnivore Logic

```
if SHELTERING_season or STORM → SHELTERING
else if NOT in activity_window → RESTING
else if carcass_at_chunk → FEEDING (scavenger priority)
else if plant_food_available → FORAGING
else if hunger_interval_elapsed → HUNTING (carnivore path)
else → RESTING
```

### Scavenger Logic (vulture, raven, jackal)

```
if carcass_exists_in_world → FORAGING toward nearest carcass chunk
else if food_item_dropped_at_chunk → FORAGING toward chunk
else → RESTING
```

# Inter-Species Cascade Rules

These rules fire during step 4 of the tick evaluation. They propagate state changes across species in the same or adjacent chunks.

---

## Predator → Prey Awareness Cascade

When a carnivore or monster population enters `HUNTING` or `PACK_HUNT`:

1. All herbivore populations in the **same chunk** → `ALERT`
2. All herbivore populations in **adjacent chunks** (within 1 step) → `ALERT`
3. ALERT state persists until the predator exits HUNTING or 1h elapses

This means deer flee the area where wolves hunt, not just the exact chunk of confrontation.

---

## Pack Cascade

Applies to `gray_wolf` and `dire_wolf`:

When the alpha (highest population_count in site) enters `HUNTING`:
- All other wolf populations at the same ecology_site → `PACK_HUNT`
- PACK_HUNT increases effective resistance by +10 for encounter rolls

---

## Scavenger Cascade

When any `wildlife_carcass` is created (from player harvest or predation):
- All scavenger populations (vulture, raven, jackal, golden_jackal) within 3 chunks → `FORAGING` toward that chunk
- Raven and vulture reach within 1–2 ticks
- Jackal within 3–5 ticks

This makes vultures a reliable carcass indicator visible in survey.

---

## Fire Fear

When an active `fire_state` exists in a chunk:
- Large species (M, L, XL) in the same chunk → `FLEEING`
- Small species (XS, S) → `SHELTERING` in place (freeze)
- Exception: `wolverine` ignores fire fear (does not flee)
- Exception: insects (mosquito, dragonfly) → `FORAGING` away from smoke (suppressed)

---

## Flee Window

When a population enters `FLEEING`:
- A `flee_expires_at` timestamp is set = now + 2h
- Until expiry: encounter chance for this population in this chunk is reduced by 80%
- At expiry: population reverts to its prior state (RESTING/FORAGING/HUNTING as appropriate)

---

## Sound Propagation

Certain chronicle actions create a noise event evaluated against nearby populations:

| Action | Noise radius | Effect |
|--------|-------------|--------|
| FELL_TREE | 2 chunks | All populations within radius → ALERT |
| CONFRONT_WILDLIFE (any outcome) | 1 chunk | Adjacent populations → ALERT |
| LIGHT_FIRE (initial flame) | 1 chunk | Large species → FLEEING |
| CRAFT (stone knapping) | 0 chunks | Same-chunk populations → ALERT |
| SLEEP (snoring) | 0 chunks | Carnivores → 5% passive attack roll per hour |

Sound events do not fire for: GATHER_PLANT, WRITE, EQUIP, OBSERVE.

---

## Ambush Hunter Exemption

Species with `ambush_hunter = true` (currently: `european_wildcat`, `common_adder`, `constrictor_snake`):

- Do **not** transition to `ALERT` before attacking
- Do **not** give the ALERT signal the chronicle normally receives during TRAVEL/GATHER
- Attack roll happens silently on encounter
- Player receives no warning in the `nearbyObjects` frame

---

## Taming Posture Read

When a chronicle attempts `TAME` or `APPROACH_CALM`:

- If any weapon is equipped by the chronicle → trust regression applied regardless of action text
- The population reads the physical posture (equipment state), not only the action description
- This is not negotiable — a drawn weapon communicates threat

# Seasonal FSM Summary

| Season | Key state changes |
|--------|-----------------|
| Spring | NESTING active (all nesting birds); maple_sap available; amphibians active |
| Summer | Maximum activity across all species; berry yield; firefly ambient; mosquito peak |
| Autumn | Rutting TERRITORIAL for cervidae; berry harvest closes; bear foraging intensifies before hibernation |
| Winter | Bear hibernation (SHELTERING); migratory birds absent; reduced foraging for all |

# Passive Encounter Logic

Introduced in V44. Evaluated during chronicle TRAVEL and GATHER dispatches.

When a chronicle moves to or acts within a chunk:

1. Query all populations in chunk with `behavior_state IN ('HUNTING', 'ALERT', 'PACK_HUNT', 'TERRITORIAL')`
2. For each population, compute `encounter_roll`:
   - `base_chance` = role_factor (CARNIVORE 0.35, OMNIVORE 0.15, HERBIVORE 0.05)
   - `× population_density` (population_count / carrying_capacity)
   - `× behavior_multiplier` (HUNTING 1.0, ALERT 1.3, PACK_HUNT 1.5, TERRITORIAL 0.8)
   - `× time_modifier` (species active window = 1.0, inactive = 0.2)
   - Subtract `FLEEING_window_penalty` (0.8 reduction if FLEEING)
3. Roll against encounter_roll → passive attack if succeeds
4. Severity = same formula as `WildlifeEncounterService.confront()` but without player tactic bonus

This means a chronicle who walks into a chunk where a wolf pack is hunting has a ~35% chance of being attacked per action tick, rising to ~52% if the pack is in PACK_HUNT state.

# Tracking Signs

Introduced in V44. Signs are readable via the TRACK intent.

| Sign type | Produced by | Condition |
|-----------|-------------|-----------|
| `PRINTS` | Any terrestrial species | Population has been in chunk within 24h |
| `SCAT` | Carnivores, omnivores | Population fed in chunk within 48h |
| `FEATHERS` | Aerial species | Population landed or nested in chunk within 24h |
| `DISTURBED_GROUND` | Large species (M+) | Any behavior state, within 12h |
| `CARCASS_SCRAPS` | Any species | wildlife_carcass was present within 72h |
| `DEN_MARKS` | Ursidae, canidae | Population site within 2 chunks |
| `TERRITORIAL_SCRATCH` | Felidae, Ursidae | TERRITORIAL state within 48h |

TRACK result depends on chronicle attention (Layer 2 specificity):
- LOW specificity → returns 1 sign type only (if present)
- HIGH specificity → returns all signs, plus behavior_state inference
- HIGH + AIM familiarity → approach can be made without triggering ALERT
